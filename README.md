# Pil Takip

Android için pil değişim takip uygulaması.

## Özellikler
- İlk değişim dokunuşunda tarih ve saat otomatik kaydedilir.
- Sonraki dokunuşta mevcut tarih düzeltilebilir veya yeni kayıt eklenebilir.
- Takvim simgesiyle tarih ve saat elle seçilebilir.
- Geçmiş kayıtlar cihazda saklanır.
- Sonraki değişim tarihi, son kayda varsayılan 28 gün eklenerek hesaplanır.
- Ayarlardan değişim aralığı 1-365 gün arasında değiştirilebilir.

## APK oluşturma
GitHub deposunda Actions sekmesine gir. Pil Takip Android APK iş akışı push sonrasında otomatik çalışır. İstersen Run workflow ile elle de başlatabilirsin. Tamamlandığında çalışmanın altındaki Artifacts bölümünden PilTakip-APK dosyasını indirip ZIP içindeki APK'yı Android cihazına kurabilirsin.

İlk sürüm debug APK olarak derlenir.
